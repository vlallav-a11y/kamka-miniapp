# KAMKA STORE — Telegram Mini App

Первая рабочая заготовка магазина для Telegram.

## Что уже есть
- каталог товаров;
- категории и поиск;
- карточка товара;
- выбор размера / объёма;
- актуальные остатки из массива `variants`;
- корзина;
- оформление заявки;
- чтение данных пользователя из Telegram Mini App;
- заготовка подключения Supabase;
- демо-режим без базы данных.

## 1. Быстрый запуск локально
Нельзя просто открыть `index.html` двойным кликом из-за ES modules. Запусти локальный сервер:

```bash
python3 -m http.server 8000
```

Затем открой:

```text
http://localhost:8000
```

## 2. Размещение на Vercel
1. Создай новый GitHub-репозиторий.
2. Загрузи туда все файлы этой папки.
3. На Vercel нажми Add New → Project.
4. Импортируй репозиторий.
5. Framework Preset: Other.
6. Build Command: оставить пустым.
7. Output Directory: `.`
8. Deploy.

После деплоя получишь HTTPS URL вида:

```text
https://kamka-miniapp.vercel.app
```

## 3. Подключение к Telegram
В BotFather:
1. `/mybots`
2. выбери бота;
3. Bot Settings;
4. Menu Button;
5. Configure menu button;
6. отправь HTTPS-ссылку Mini App;
7. задай название кнопки, например `Открыть магазин`.

Также можно настроить Main Mini App для большой кнопки запуска в профиле бота.

## 4. Supabase
Создай проект Supabase и вставь `Project URL` и `anon key` в `config.js`.

### Таблица products
Минимальная схема:

```sql
create table products (
  id bigint generated by default as identity primary key,
  brand text not null,
  name text not null,
  category text not null,
  price numeric not null,
  image_url text,
  variants jsonb not null default '[]'::jsonb,
  active boolean not null default true,
  created_at timestamptz not null default now()
);
```

Пример `variants`:

```json
[
  {"name":"M","stock":1},
  {"name":"L","stock":2}
]
```

### Таблица orders

```sql
create table orders (
  id bigint generated by default as identity primary key,
  telegram_user jsonb,
  telegram_init_data text,
  customer jsonb not null,
  items jsonb not null,
  total numeric not null,
  created_at timestamptz not null default now()
);
```

## Важно перед реальным запуском
Текущая версия — frontend MVP. Для настоящего магазина нельзя доверять `Telegram.WebApp.initDataUnsafe` на клиенте. Перед созданием оплачиваемых/подтверждённых заказов нужно сделать backend/Edge Function, которая проверяет `Telegram.WebApp.initData` по Bot Token.

Также лучше не давать клиентскому anon-ключу возможность напрямую создавать/редактировать произвольные товары. Для production настрой RLS в Supabase и отдельный защищённый endpoint для заказов.
